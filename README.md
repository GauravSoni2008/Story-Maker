# 📖 Story Maker

Story Maker is an AI-powered web application that transforms a few keywords into engaging, creative stories. Whether you're looking for a funny tale, fantasy adventure, mystery, or sci-fi narrative, Story Maker generates unique stories in seconds using modern AI models.

## ✨ Features

* 📝 Generate complete stories from a list of keywords
* 🎭 Multiple storytelling styles and genres
* ⚡ Fast AI-powered story generation
* 🎨 Clean and responsive user interface
* 📱 Works on desktop and mobile devices
* 🔄 Generate unlimited unique stories

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/GauravSoni2008/Story-Maker.git
```

Move into the project folder:

```bash
cd Story-Maker
```

Install dependencies:

```bash
npm install
```

Create a `.env` file:

```env
API_KEY=YOUR_API_KEY
```

Start the development server:

```bash
npm start
```

or

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```

---

## 💡 Usage

1. Enter one or more keywords.
2. Click **Generate Story**.
3. Wait a few seconds while the AI creates your story.
4. Read, copy, or regenerate as many stories as you like.
